## Quick Reference

### Style: Vibrant & Block-based
- Bold, energetic, playful, block layout, geometric shapes
- High color contrast, duotone, modern

- **Body:** Poppins

### Key Effects
- Large sections (48px+ gaps)
- Animated patterns
- Bold hover (color shift)
- Scroll-snap
- Large type (32px+)
- 200-300ms transitions
